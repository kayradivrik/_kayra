# Sonsuscato (Kayra Divrik) - Portfolio Website

Siber Güvenlik, Linux Sistem Yönetimi ve Web Teknolojileri üzerine hazırlanmış kişisel portfolyo web sitesi.

## Özellikler

- **Yapay Zeka & Animasyonlu WebGL Arka Plan:** Yüksek performanslı canvas fog efekti
- **Dinamik GitHub Proje Entegrasyonu:** Canlı API üzerinden repoların çekilmesi
- **Responsive Tasarım:** Mobil cihazlarda dokunmatik snap slider
- **Siber Güvenlik & Linux Yetenek Matrisi:** C++, Linux, Next.js, Python, TypeScript yetkinlikleri

## Geliştirici Kurulumu

```bash
npm install
npm run dev
```

Dev sunucusu `http://localhost:3000` adresinde çalışır.

## Teknoloji Yığını

- **Framework:** Next.js (App Router, Static Export)
- **UI & Styling:** React, TypeScript, Tailwind CSS
- **Animation:** Framer Motion
- **Icons:** Lucide React, React Icons
